📋 REQUISITOS (instalar antes de usar):
   ✅ Node.js → https://nodejs.org/ (versión LTS)
   ✅ Python  → https://www.python.org/ (marcar "Add to PATH")

───────────────────────────────────────────────────────────────────────

🚀 EJECUCIÓN RÁPIDA:

   1. Haz doble clic en: run_demo.ps1
   
   2. Si sale un error de seguridad, abre PowerShell como Admin y ejecuta:
      Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   
   3. Selecciona la opción 1 (Frontend + Backend)
   
   4. ¡Listo! Abre tu navegador en: http://localhost:5173

❓ PROBLEMAS COMUNES:

   "npm no se reconoce"
   → Instala Node.js y reinicia PowerShell

   "python no se reconoce"
   → Instala Python (marca "Add to PATH") y reinicia PowerShell

   "No se puede ejecutar scripts"
   → Ejecuta en PowerShell Admin:
     Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

   Puerto en uso
   → Cierra otras aplicaciones que usen los puertos 5000 o 5173
